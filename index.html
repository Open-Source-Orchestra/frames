The Open Source Orchestra Frame

A frame is everything around the edge of a screen. Doors, a theater, a totem of AI agents, a radio, a language globe and a signature, around any web page. One script tag. One open dataset. Copyleft forever.

🔌Put a frame on your door

Paste one line before </body>. That gives you the universe frame of the Open Source Orchestra:

<script src="https://frames.opensourceorchestra.org/frames.js" defer></script>

Point it at your own dataset to make it yours:

<script src="https://frames.opensourceorchestra.org/frames.js"
        data-frame="/my-frame.json" defer></script>

One tag for every page of every door: the frame picks the door's own small dataset by host name (make your door's frame in 5 minutes):

<script src="https://frames.opensourceorchestra.org/frames.js"
        data-door="auto" defer></script>

Add ?frame=outline to any framed page to see its blueprint, ?frame=fresh to replay the first visit, ?frame=off to hide the frame for one page view. The ⚙ in the credit mark (bottom-left) turns the frame, or any piece, off and on — remembered in your browser only; a small 🎻 dot brings it back. See the frame is the mark for the gallery of door frames.

🍴Fork it, make it yours

  1. Fork github.com/Open-Source-Orchestra/frames.
  2. Edit one file. Open frames/minimal.json, or use the frame builder, and set your own doors, songs, films and agents.
  3. Switch on GitHub Pages (Settings → Pages → main, root). Your frame is live at https://<you>.github.io/frames/. Add the script tag to your site and you are framed.

Bring your own signature too: tools/vectorize-signature.py turns a drawing of your name into pen strokes that sign themselves. Shaka's signature stays his.

🧬The dataset is the frame

Every slot around the screen is a list in one JSON file: top-left, left, bottom-left, top-right, right, bottom-right and an overlay for the signature. Every item is one button.

{
  "frame": "osoframes/0.1",
  "id": "my-door",
  "slots": {
    "top-left":    [ { "kind": "globe" } ],
    "left":        [ { "kind": "door", "emoji": "🎼", "label": "Songbook",
                       "href": "/songbook/", "tip": "Songs you can sing along to." } ],
    "right":       [ { "kind": "totem", "hub": "https://…", "faces": [ … ] } ],
    "bottom-right":[ { "kind": "radio", "tracks": [ … ] } ],
    "overlay":     [ { "kind": "signature", "src": "my-signature.svg" } ]
  }
}

♾️The gift keeps giving: copyleft

The frame is free to use, change, host and even sell. In return, two promises travel with every copy, forever:

Forks stay open

The code is AGPL-3.0-or-later. Whoever gets your version gets the same freedoms. If you run a changed frame on a website, you offer its source to the people who use it.

The credit travels

Under AGPL section 7(b), every copy keeps this line visible: Built on Open Source Orchestra Frames by Open Source Orchestra: Shaka Lei Kaumaka & the AI ʻohana. Add your name next to ours. See NOTICE.

Plain words, not legal advice. Copyleft covers the frame and works based on it; a site that only loads the unchanged frame keeps its own license for its own content.

🕊️The laws of the frame

  • Once, then still. Every animation and every tip plays one time per visitor. No loops, no nagging.
  • Nothing connects until you act. No chat, audio, video or translation loads before a click. No cookies, no trackers.
  • Machines say they are machines. The agents on the totem are AI, and they tell you.
  • Consent before people. A song or a film is listed only with the yes of everyone in it.
  • Everyone can use it. Keyboard, screen readers, reduced motion and small screens are first-class.
